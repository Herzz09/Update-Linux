#############################################################################################

#############################################################################################

2. If your download is automatic to the folder downloads, run this:

mv ~/Downloads/up.sh ~/Desktop/up.sh

#############################################################################################

3. Go to de desktop.


Ex. [ENGLISH]:

cd ~/Desktop

########################

Ex. [SPANISH]:

cd ~/Escritorio

########################

Ex. [PORTUGUESE]:

cd ~/Área\ de\ Trabalho

#############################################################################################

4. Open the terminal and run this command:


chmod +x up.sh && sudo ./up.sh

#############################################################################################

5. When you run again the script:

cd ~/Desktop (cd ~/Escritorio) (cd ~/Área\ de\ Trabalho)

sudo ./up.sh
