# Update-Linux
Update apps in the linux

########################################################################

1. Save the file desktop.


########################################################################

2. Go to de desktop.


Ex. [ENGLISH]:
cd ~/Desktop

Ex. [SPANISH]:
cd ~/Escritorio

Ex. [PORTUGUESE]:
cd ~/Área\ de\ Trabalho

########################################################################

3. Open the terminal and run this command:


chmod +x up.sh && ./up.sh

########################################################################

4. When you run the script, go to de desktop and run this:

cd ~/Desktop (cd ~/Escritorio) (cd ~/Área\ de\ Trabalho)

./up.sh
